# 飞书文档权限规范（全局）

## 适用范围

每次通过飞书 API 创建新文档时，必须执行以下权限设置。

## 权限要求

1. **陆嘉欣** — 管理权限（full_access / owner）
2. **Mobile Growth 群全体成员** — 编辑权限（edit）
   - 群 chat_id: `oc_efab06bc2b4f283575440499e8f802e2`

## 执行方式

创建飞书文档后，使用文档权限 API 完成以下操作：

1. 将文档的「谁可以查看/编辑」设置为：以 Mobile Growth 群（`oc_efab06bc2b4f283575440499e8f802e2`）为协作者，权限级别为**编辑（edit）**。
2. 单独为**陆嘉欣**添加**管理权限（full_access）**。

## 注意事项

- 这是全局规则，适用于所有通过本 Agent 创建的飞书文档，无论哪个分析场景。
- 如果飞书 API 不支持直接对群添加协作者，则需逐个为群内成员添加编辑权限。
- 优先使用「群组协作者」方式（如果 API 支持），以避免未来群成员变动时失效。
